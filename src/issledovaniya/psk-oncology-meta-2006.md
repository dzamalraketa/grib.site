PSK (Polysaccharide-Krestin) — очищенный протеогликан из Trametes versicolor, зарегистрированный в Японии как вспомогательный препарат для онкологии. Метаанализ включает исследования с 1970-х по 2000-е годы, преимущественно японские работы.

Важно: данные получены на человеческих когортах, без использования моделей на животных. PSK использовался как адъювант (дополнение), а не замена стандартной терапии. Любые решения по онкологическому лечению должны приниматься только совместно с лечащим врачом.
